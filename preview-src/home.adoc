== One tile API in front of every map source you use.

[.lead]
Tilegroxy shines when you consume maps from multiple sources.
It isn't tied to any one mapping backend and can be configured to proxy, cache and transform tiles from any of them.

== Features

[.features]
--
.Sources
* Proxy to ZXY, WMS, TMS, WMTS, or other protocol map layers
* Serve PMTiles archives and PostGIS vector tiles
* Blend, crop and transform tiles from multiple sources

.Cache
* Cache tiles in disk, memory, s3, redis, and/or memcached
* Seed and purge caches ahead of time
* Per-layer TTLs and cache control headers

.Security
* Authenticate with static keys, JWT, or custom logic
* Restrict pattern placeholders with validators
* Multi-tenant layers and caches

.Operations
* Hot reload configuration without dropping requests
* OpenTelemetry traces, metrics and logs
* Analytics events to ClickHouse or PostgreSQL
